How the Cutout Is Actually Produced

This tool runs a segmentation model directly in your browser using WebAssembly. The model examines the image and predicts, pixel by pixel, how likely each one is to belong to the foreground subject. Those predictions become the alpha channel of the PNG you download, which is why fine detail such as hair renders as partial transparency rather than a hard edge.

Because everything runs locally, your photo is never uploaded. The model weights are fetched once and cached by the browser, so the first run takes longer than subsequent ones. On a mid-range laptop a typical photo completes in a few seconds; older phones take noticeably longer because the work is CPU-bound.

Output is always PNG. JPEG has no alpha channel, so saving a cutout as JPEG would fill the transparent area with solid white and defeat the purpose.

Getting the Cleanest Result

Contrast between subject and background matters more than resolution. A person photographed against a plain wall cuts out almost perfectly, while the same person against a bookshelf of similar colours produces edge artefacts no model reliably avoids.

Wispy hair, fur, transparent glass and motion blur are the recognised hard cases across every background removal tool. If the result needs to be perfect for print, expect to touch up those areas in an image editor afterwards.

Very large images are slower without being better. Downscaling a 6000-pixel photo to around 2000 pixels before processing usually produces an identical-looking cutout in a fraction of the time.
